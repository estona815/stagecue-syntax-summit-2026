# StageCue

StageCue is a small, original domain-specific language for prototyping theater cue timing. A browser editor parses line-based scripts into a show timeline, stage-light visualization, caption preview, procedural sound cue, and diagnostics for syntax mistakes or overlapping cue windows.

Open `index.html` in a browser, or serve this folder with `python3 -m http.server 8792`. No build step or account is required.

## Syntax

```text
show "A Midnight Conversation"
length 90s

cue "Opening" at 0s for 20s
  light left 65%
  light center 30%
  caption "The room is quiet."
  sound chime
end
```

- A show has one title, one length in seconds, and at least one cue.
- Each cue has a start time and duration. Light levels are scoped to the cue; unspecified lights are off.
- `light` accepts `left`, `center`, or `right` and a value from 0% to 100%.
- `sound` accepts `none`, `chime`, or `pulse`. These are generated by Web Audio; no audio files are loaded.
- Overlapping cues are reported as warnings. During an overlap the later cue is shown in the preview.
- Syntax errors prevent playback. The editor reports source line numbers.

This is an educational simulation and does not connect to live performance hardware. It was built for Syntax Summit during its hackathon period. The visual concept was AI generated and the implementation, sample scripts, grammar, parser, and artwork are original to this project.
