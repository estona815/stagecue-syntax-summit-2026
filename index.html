THE LANGUAGE

Small syntax. Clear timing.

StageCue parses a line-based show script into cue blocks. Each cue has a start time and duration, plus optional light levels, a caption, and a built-in procedural sound. Light settings apply only to that cue. Overlapping cue windows are flagged, while playback stays available so you can inspect the conflict.

show "A Midnight Conversation"
length 90s

cue "Opening" at 0s for 20s
  light left 65%
  light center 30%
  caption "The room is quiet."
  sound chime
end
Commands

show title · length seconds · cue name / start / duration · light left|center|right 0–100% · caption quoted text · sound none|chime|pulse · end

Created as an educational prototype. Do not use this simulation to operate a live performance.
